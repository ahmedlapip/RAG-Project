# WFRS
Wikipedia & File based RAG System

## How to use 
### Requirements
1. Download Pyhton 3.14 version or later 
``` bash 
sudo dnf install python3.14
```
2. Create env for project
``` bash
python3 -m venv .Mini-RAG
```
3. install Requirments
``` bash 
pip install -r requirments.txt 
```
4. Env Variables
``` bash
cp .env.example .env
```
